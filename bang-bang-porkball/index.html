操作說明

  • 點地圖一下=自動走過去・點兩下=放貢丸(滑鼠/觸控皆可)
  • ↑↓←→ / WASD 移動(一步一格)
  • 空白鍵 放置貢丸・1~9 切換貢丸(夜市 O 香腸、P 米腸)
  • E/J 踢/騎乘前方貢丸(耗 MP)・G 防護盾(耗 MP,擋一次爆炸)
  • Q 吸塵器・F 垃圾車(清前方貢丸)
  • Z 食物夾(夾起/放下)・X 隔熱手套(丟)・C 彈弓・V 藍白拖
  • K 放出/收起 老鼠・L 蟑螂・R 重新開始
  • `(Esc 下方)切換 2D / 3D 畫面

3D 視角操作

  • 左鍵拖曳 / 單指滑動:旋轉視角・滾輪 / 雙指捏合:縮放・右鍵拖曳:平移
  • 上方按鈕可切換 45° / 俯視 / 側視 / 跟隨 / 第一人稱
